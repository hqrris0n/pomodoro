Overall idea: an aesthetic, cafe themed pomodoro timer

Keep everything organized throughout the entire project, and delete any folders or files that are no longer needed by the end of production. This is meant to be deployed onto a small, low powered nas for a couple of people to use at the same time, but the device is very strapped for ram, so take that into consideration when designing the architecture and picking out what technologies we want to use. We still want it maintainable and human readable. 

Features:
Allow for drink selection with pictures. Maybe keep a json file or a location where I can easily keep track of the drinks to add to remove them if I wanted like cafe.pauwee.com
Timer with play pause buttons
Settings page with a section for sounds to play, and they can save a collection of sounds at different volumes. There should be many different kinds of ambient noises like background chatter, coffee grinders, etc. like soundscapes from pomodorocrew.com or imissmycafe.com
Various background like https://studyatcafe.com is also nice with the cozy ambiance and warm lighting. 


Flow:
Open the website to a timer selection with defaults of 5, 15, 30, 60 min, and custom with a slider or an input box (that dynamically updates with the slider up to a max of 3 hours with a drink selection right under it and a todo list below that.  After we fill those out, we move to the timer screen where the drink is slowly getting made by little, cute characters running around, and pouring mini versions of the drink into a glass until the big glass cup is full. The glass cup should correlate to the time, but doesn't have to line up with the characters pouring it in. There should be a todo list visible as well so that the user can check things off as they go through. One check list can persist through different rounds of the timer.
